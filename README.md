# Sprout

A playful, responsive habit tracker. Built with Vite, JavaScript, and Lucide icons.

## Run

```sh
npm ci --cache /tmp/sprout-npm-cache
npm run dev
```

Build for production with `npm run build` and serve with `npm run preview`.

Habits, daily completions, and your preferred name are saved in this browser's localStorage. Streaks count consecutive completed days; yesterday's streak stays active until today's opportunity has passed. No account, backend, or API keys required. Clearing browser storage removes saved data.

## Features

Create and edit habits, set daily goals and times, choose icons and one of six color-coded categories, and filter your routine. Check-offs update streaks, progress, and the growing plant. The Progress tab shows 21-day history and earned milestones; the Calendar supports browsing earlier months. Quick-start suggestions prefill a new habit. Preferences include a JSON backup download. Motion respects the reduced-motion setting.
